# Fitness Tracker

Entrenamiento, nutrición y hábitos en una sola app web instalable (PWA). Funciona sin internet y tus datos se quedan en tu teléfono.

## Instalar en iPhone
1. Abre la URL de GitHub Pages del repositorio en **Safari**.
2. Toca **Compartir** → **Agregar a pantalla de inicio**.
3. Ábrela desde el ícono. Desde ese momento funciona offline.

## Desarrollo
```bash
npm install
npm run dev
```
Publicar una versión nueva: `npm run deploy`.

Para probar en el iPhone mientras desarrollas, abre `http://<IP-de-tu-PC>:5173` en Safari, conectado a la misma WiFi.
